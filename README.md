# 💰 Expense Tracker

A modern, responsive Expense Tracker built with **HTML, CSS, and JavaScript**.

Track income and expenses, manage your monthly budget, visualize spending, and export financial reports as PDF — all from your browser.

🔗 **Live Demo:**  
https://tanakevy-droid.github.io/Expense-Tracker-/

---

## ✨ Features

### 💰 Income & Expense Tracking
- Add income transactions
- Add expense transactions
- Automatically calculate your current balance
- Delete transactions
- Data is saved locally on the device

### 🏷️ Categories
Organize transactions using categories such as:

- 🍔 Food
- 🚗 Transport
- 🛒 Shopping
- 🏠 Rent
- 💡 Bills
- 🎓 Education
- 💊 Health
- 🎉 Entertainment
- 💼 Salary
- 📦 Other

### 📊 Spending Analytics
View your spending by category using an interactive pie chart.

### 🎯 Monthly Budget
Set a monthly spending budget and monitor:

- Total budget
- Amount spent
- Remaining budget
- Budget progress

The progress indicator changes as spending increases.

### 🔍 Search
Quickly search through your transactions by description.

### 📄 PDF Export
Generate a PDF report containing:

- Total income
- Total expenses
- Current balance
- Transaction history
- Categories
- Amounts
- Report generation date

### 📱 Responsive Design
The application is designed to work across:

- Android phones
- Tablets
- Desktop computers
- Modern web browsers

### ⚡ Progressive Web App
The application includes PWA functionality so it can be installed on supported devices and used offline.

---

# 🛠️ Technologies

This project uses:

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Chart.js
- jsPDF
- Progressive Web App technologies

No database or server is required for the basic application.
